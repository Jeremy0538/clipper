    Welcome to Clipper

    Clipper keeps the last minutes of your game ready. Press one key and that moment is saved as a clip. This guide sets up keys, sound and quality in about a minute. You can change everything later in Settings.

    Getting the recorder ready…

    The first start downloads the recording engine (about 150 MB). You can already go on.

    Your keys

    Click a key, then press the new combination. The key still reaches your game, so pick one you don't use in-game.

    Make a test clip

    Check that everything works before you need it. For the best test, start your game first: Clipper then records it like it normally will. Without a game it records your screen, and "Only the game" sound stays silent.

    During the test: talk, play some game sound, and if you're in a Discord call, let a friend say something.

    Game sound
    Discord
    Microphone

    Something missing? Go back to fix it, then try again. The test clip is under Clips, where the editor plays Game, Discord and Mic separately.

    You're ready

    1. Start a game. Clipper starts clipping by itself (the status bar turns green).
    2. Something cool happened? Press F8. You hear a short sound.
    3. F9 starts or stops a full recording, F10 takes a screenshot.
    4. Your clips appear under Clips: trim them, change the volumes, copy them to Discord.

    Clipper keeps running in the tray when you close the window. Settings → Startup can run this guide again.
